# Python Automation Tool – File Organizer

## Description
A Python-based automation tool that organizes files into separate folders based on their file extensions.

## Features
- Organizes text files into Text_Files.
- Organizes image files into Images.
- Organizes Python files into Python_Files.
- Automatically creates folders.
- Moves files using Python.

## Technologies Used
- Python
- OS Module
- Shutil Module

## How to Run
1. Install Python.
2. Create a folder named sample files.
3. Add files to the sample files folder.
4. Run the following command:

```bash
python organiser.py
```
